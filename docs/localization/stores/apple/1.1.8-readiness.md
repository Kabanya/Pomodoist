# Apple 1.1.8 preparation

Prepared on 2026-11-06 for iOS and Mac App Store, with manual release.
This is a preparation record, not a submission or publication record.

## Release contents

- Marketing version `1.1.8`, build `132` on both platforms.
- Ten storefront languages: English, Russian, German, Spanish, French, Arabic,
  Simplified Chinese, Brazilian Portuguese, Japanese and Korean.
- Updated what's-new text applied to both storefront drafts. Read-back dry runs
  report no metadata changes.
- Added 104 missing translations for dependencies and urgency across eight ARB
  catalogs, plus 12 missing Watch sync-status translations. Brazilian Portuguese
  validation now follows Flutter's parent-catalog inheritance.
- Generated 297 additional localized screenshots: 90 iPhone, 90 iPad, 90 Mac
  and 27 Watch. Existing 33 English store images are retained by the uploader.
- Uploaded signed iOS and macOS build `132` to TestFlight before the user
  requested no App Store uploads. Apple validation and upload were acknowledged;
  processing is not yet verified. No build has been attached to either store
  version.
- Stopped the screenshot command during its dry-run phase at the user's request.
  Read-back confirms only the existing 33 English screenshots remain; all
  non-English sets have zero uploaded images. The complete local matrix passes preflight.
  Do not upload screenshots or attach builds to App Store versions without a
  new user instruction.

## Later iPhone refresh

The current iPhone series is generated separately under
`output/app-store-screenshots/`: ten production Flutter screens with English UI
and meaningful fixed English demo work, composed into 100 covers across all ten
languages. This supersedes the iPhone captures in the initial localized matrix;
the initial iPad, Mac and Watch artifacts remain historical preparation output.
The fixture contains four projects, 36 tasks, five habits and 51 completed focus
intervals. Calendar and Timeline include timed appointments; Quick Add is closed
before capturing subsequent routes.

Run `make app-store-assets APP_STORE_ASSET_ARGS="--verify"`. The command captures
and renders independently twice, checks identical PNGs and provenance, and
exports a deterministic `covers.zip`, source/environment manifest and local
gallery. The workflow is maintained in the Apple README and the local
`pomodoist-store-assets` skill. It performs no App Store Connect requests.
The optional iPad/Mac path also passed 20 production-route captures and 200
localized composition checks. Independent repeat identity was checked for the
100-cover iPhone refresh.

## Remaining validation

The full Flutter suite is not green. Before it stalled, 3088 tests passed, one
was skipped and 11 failed. The stalled `global_quick_add_window_test.dart` run
was stopped after more than six minutes without progress; its shutdown error
is also recorded. The App Group timeout passed in isolation. The sidebar voice
sheet failure reproduced in isolation. Other failures cover interaction
controls, calendar selection, shortcut hints and Quick Add focus retention;
they have not been fixed or established as baseline failures in this work.

Automated captures do not verify account synchronization, purchases, physical
devices, Watch/iPhone connectivity, or linguistic quality. No manual visual
browser review was performed. Check App Privacy publication and any remaining
App Store Connect requirements before submission. No version was sent for
review or published.
