# Pomodoist 1.1.5

Habit icons and synchronization recovery.

Stable tag · Source date: 2026-10-07 · Commit: [`f9ada60d`](https://github.com/Kabanya/Pomodoist/commit/f9ada60dfa6bf39c2247219e60de2ee15b10774e)

Changes compared with `v1.1.4`.

## User experience changes

- Personalize habits with an emoji or built-in icon, and reset the icon when needed.
- Review Focus time by project and task for today or the last seven days, and open tasks directly from reports.
- Set a task's schedule from its details and use an additional Focus keyboard shortcut.
- Restart synchronization from settings and see when changes are pending or need recovery.
- Keep pending account changes available for recovery across account switches.
- Save tasks and edits more reliably immediately after opening the app.

## Backend and developer changes

- Backend: habit icons and habit synchronization metadata gain dedicated migrations and validation; server startup adds sync-health diagnostics.
- Local database: schema version 11 adds habit icons, and version 12 adds account recovery snapshots. Migration steps tolerate previously applied table/column additions.
- Sync recovery: ownership coordination, import/pull/push handling, and recovery snapshots are integrated. Database reset and seed creation run in the same transaction.
- Startup fix: the outbox reads the persisted owner while the owner stream is loading, retaining stale-owner protection without waiting for that stream inside a transaction.
- Platforms and tooling: the macOS DMG build script requires signing and notarization; public-boundary checks and outdated widget-test targets are corrected.
