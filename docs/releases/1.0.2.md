# Pomodoist 1.0.2

Focus without an account and more reliable planning.

Stable tag · Source date: 2026-09-04 · Commit: [`4dcd0d22`](https://github.com/Kabanya/Pomodoist/commit/4dcd0d22d2ca710d77097418e95d24344b9bffbd)

First stable application tag in the repository. This entry establishes the baseline for subsequent release comparisons.

## User experience changes

- Try Focus as a guest, with a dedicated timer and guest data kept separate from signed-in accounts.
- See task time status across task views, use multi-task selection actions, and create reusable Focus presets.
- Plan with clearer Timeline blocks and more adaptable desktop Kanban columns; task schedules stay current after synchronization.
- Add tasks with clearer success and failure feedback, and use improved mobile drag and drop.
- Use Stripe Checkout for subscriptions and server-backed Google Calendar synchronization with fewer duplicate events.
- Windows uses the Skia renderer by default; iPhone and iPad startup fixes address the white-screen issue.

## Backend and developer changes

- Backend and sync: Google Calendar synchronization moves to the server; account sync compacts its queue and preserves schedule metadata.
- Data ownership: guest Focus storage is isolated, account-owner transitions are serialized, and guest ownership races are fixed.
- Billing: Stripe Checkout is integrated alongside account-free Pro handling.
- Platforms and tooling: native macOS menu commands, environment-driven deployment commands, a working Windows installer, and pinned Flutter versions for desktop/web packaging.
