# Pomodoist 1.1.1

Project maps, guided onboarding, and clearer task navigation.

Stable tag · Source date: 2026-09-28 · Commit: [`8d9a70ff`](https://github.com/Kabanya/Pomodoist/commit/8d9a70ff3ddf0317d12a830ed2b239b5edaf03fe)

Changes compared with `v1.1.0`.

## User experience changes

- Use updated Today and Upcoming views with clearer task grouping and subtask context.
- Browse projects as a list or map, with separate saved view preferences for the project catalog and individual project views.
- Search the project catalog more effectively and display subtasks with connected or grouped branches.
- Try task and theme previews during onboarding, then choose whether to take the guided app tour.
- Use improved Focus actions and task-detail navigation, including keyboard shortcuts and better-positioned context menus.
- Keep labels and shared-project content more consistent as access and synchronized data change.

## Backend and developer changes

- Sync and storage: label/project synchronization and shared-scope cleanup are reworked, including transfer and access-change handling.
- Preferences: catalog view mode is stored independently from project view mode; branch expansion and subtask presentation use shared view-model projections.
- Architecture: task views use repository/view-model boundaries; the onboarding tour dependency cycle is removed.
- Integrations: OpenClaw integration configuration and account email delivery are updated.
- UI contract: project view modes are list and map; connected and grouped branches are subtask presentation styles.
