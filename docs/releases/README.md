# Release notes

Stable application releases from `v1.0.2` through `v1.1.5`.

Each document separates **User experience changes** from **Backend and developer changes**.
Changes are compared between consecutive stable release tags, including all changes
introduced between those tags. Source dates are commit dates.

`v1.0.2` is the first stable application tag in the repository and establishes the baseline.
There is no stable `v1.0.6` tag, so `v1.1.0` is compared with `v1.0.5`.
