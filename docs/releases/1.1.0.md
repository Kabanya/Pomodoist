# Pomodoist 1.1.0

Shared projects and a redesigned calendar.

Stable tag · Source date: 2026-09-26 · Commit: [`333d895e`](https://github.com/Kabanya/Pomodoist/commit/333d895ea3fd50633d82c4c76a7e7a1c1782c021)

Changes compared with `v1.0.5`.

## User experience changes

- Collaborate through shared projects with invitations, member roles, task assignments, comments, ownership transfer, and shared Focus history.
- Make a shared project private again when collaboration ends. Public-link controls are removed from the sharing dialog.
- Plan in the redesigned calendar, with a dedicated mobile layout, clearer task cards, and shared scheduling actions.
- Customize bottom navigation and use consistent action menus across views.
- Work with Kanban boards that keep column identities and ordering consistent across projects and synchronized devices.
- Add tasks through improved Quick Add and voice capture, and learn the app through refreshed swipeable onboarding.
- Use expanded localization, including Portuguese, Japanese, and Korean, and clearer Google Calendar synchronization errors.
- Use more accessible Focus timer controls. Subscription flows add support for trials and returning-customer offers, subject to eligibility.

## Backend and developer changes

- Backend API: API v1 introduces versioned schemas and functions for account management and collaboration.
- Collaboration: shared scopes, invitations, roles, ownership transfer, unshare, and revision-based conflict handling are implemented. Shared-root deletion uses the server scope operation.
- Sync: Kanban changes carry shared revisions and resolve conflicts; mirrored status identities prevent duplicate or misplaced columns. Session handling rejects stale signed-out snapshots.
- Architecture: Flutter moves into apps/flutter and adopts MVVM, repository/service boundaries, smaller modules, and explicit environment entry points.
- Billing: Stripe trial and return-offer flows and Apple offer configuration are introduced; offer handling remains platform-specific.
- Tooling: staging/production flavors and branch-based server tagging/deployment are introduced. Linux builds read their own environment profiles; automatic macOS DMG releases are paused in this version.
