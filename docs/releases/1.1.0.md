# Pomodoist 1.1.0

## App Store release notes

- Plan your work with the redesigned calendar and improved Kanban workflows.
- Share projects and keep task changes synchronized across collaborators.
- Add tasks faster with improved Quick Add, voice capture, and onboarding.
- Use more languages across the app and companion tools.
- Enjoy subscription trial and returning-customer offers where available, plus
  reliability improvements across devices.

## Release verification

The release candidate uses `1.1.0+111`; build 110 has already been uploaded to
App Store Connect for iOS and must not be reused for changed code.

Automated verification on September 25, 2026:

- Full Flutter suite: 2,032 tests passed.
- Flutter analyzer: no issues.
- Server suite: 335 tests, including 70 steps, passed.
- Stripe entrypoint type checks and public/architecture/web build contracts passed.
- Release publication tests cover Linux, Windows, and Android completion and
  preserve release-candidate status. The paused macOS DMG job is optional;
  App Store macOS delivery remains a separate TestFlight workflow.

A successful build or upload does not establish App Store publication or tester
availability. Record final CI, upload, processing, and review results separately.

## Billing rollout

The release owner authorized activating revised prices and offers before public
availability of 1.1.0 on September 25. App Store Connect requires the regular
price change to start no earlier than September 26. The intended configuration
covers all 175 existing storefronts, using Apple's US-based equalizations:

| Plan | Regular US price | Introductory offer | Return offer |
| --- | --- | --- | --- |
| Monthly | USD 4.99 | 7 days free | USD 1.99/month for 3 months |
| Annual | USD 29.99 | 7 days free | USD 14.99 for one year |

Lifetime products are unchanged. Apple price decreases apply to future renewals;
existing Stripe subscriptions are not rewritten by creating a new catalog.
The older 1.0.5 paywall may describe newly configured introductory metadata
incorrectly; Apple controls the actual purchase terms.

See [subscription offers](../subscription-offers.md) for mode guards, exact
server configuration, eligibility, and remaining Apple signature requirements.
Configuring Apple promotional metadata alone does not activate the server signer.
