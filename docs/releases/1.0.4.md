# Pomodoist 1.0.4

Desktop updates and voice capture across platforms.

Stable tag · Source date: 2026-09-08 · Commit: [`e9d16fb5`](https://github.com/Kabanya/Pomodoist/commit/e9d16fb5cb8cb4bd4ecbcc9adac7d9e53e1ba2b7)

Changes compared with `v1.0.3`.

## User experience changes

- Install verified automatic updates on Windows and Linux, with clearer download errors.
- Use the improved Telegram Mini App and bot for task management and Focus.
- Create tasks by voice on non-Apple platforms through cloud transcription.
- Connect OpenClaw to manage tasks and synchronized Focus through OAuth and MCP.
- Spot overdue all-day tasks more easily through corrected date highlighting.

## Backend and developer changes

- Backend and integrations: authenticated OpenRouter transcription handles non-Apple recordings; duration limits and browser audio ownership are enforced.
- Agent integration: OpenClaw uses OAuth-authorized MCP task operations and synchronized Focus.
- Desktop updates: downloaded updates are verified and download failures are preserved for the UI.
- Tooling: Telegram joins deploy-all with explicit environment targets, and Android gains a cross-platform Make build target.
