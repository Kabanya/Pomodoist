# Pomodoist 1.0.3

Android, Chrome, Telegram, and independent hosting.

Stable tag · Source date: 2026-09-07 · Commit: [`b8db2ed3`](https://github.com/Kabanya/Pomodoist/commit/b8db2ed37fd725ad7f967c096db582abc0234e8b)

Changes compared with `v1.0.2`.

## User experience changes

- Use Pomodoist on Android with a production-signed release build.
- Capture and manage tasks from the new Chrome extension.
- Manage tasks and Focus sessions directly in Telegram chats.
- Capture tasks by voice with a more usable recording panel and improved recognition and error feedback.
- Run an independently hosted Pomodoist instance using the included hosting setup.

## Backend and developer changes

- Backend and integrations: Telegram adds in-chat task and Focus operations with separate staging and production profiles.
- Self-hosting: independent hosting configuration, setup validation, and serialized image pulls are added.
- Voice: Apple system transcription and recording-panel lifecycle handling are expanded, with native and widget regression coverage.
- Platforms and tooling: Android signing validation, Chrome build automation and privacy documentation, and versioned Windows/Linux release assets are added. Desktop artifact checks inspect packages without launching them.
- Release tooling: English notes include the full commit range since the previous release tag.
