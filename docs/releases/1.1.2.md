# Pomodoist 1.1.2

Project files and more useful task cards.

Stable tag · Source date: 2026-09-29 · Commit: [`f5f276a5`](https://github.com/Kabanya/Pomodoist/commit/f5f276a52cbe9163089db163ee0874b5d8a55e54)

Changes compared with `v1.1.1`.

## User experience changes

- Attach and manage files within projects.
- Choose task card layouts and use compact details in task lists.
- Add a comment while creating a task in Quick Add.
- Use quieter Focus controls with fewer success notifications.
- Receive clearer App Store connection errors; transient StoreKit failures and catalog timeouts are retried.

## Backend and developer changes

- Backend and storage: project-file support adds file-management contracts, access/security coverage, and storage cleanup. SQL cleanup no longer shadows a record variable.
- Client architecture: file management is routed through repository contracts; AdaptiveShell layout and widget structure are corrected.
- Billing: StoreKit retries no-response and catalog-timeout failures, with localized recovery text. Local macOS staging builds explicitly use the test StoreKit catalog.
