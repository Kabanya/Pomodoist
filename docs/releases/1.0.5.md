# Pomodoist 1.0.5

A more personal and faster planning interface.

Stable tag · Source date: 2026-09-10 · Commit: [`5ef9a061`](https://github.com/Kabanya/Pomodoist/commit/5ef9a061aa6cabd50698835f75e8edcd3ee11c08)

Changes compared with `v1.0.4`.

## User experience changes

- Customize your workspace with theme presets, a custom theme editor, project icons, persistent interface zoom, and adjustable task-row spacing.
- Use redesigned Today and Browse screens, grouped sidebar navigation, and task details in a contextual side panel.
- Find tasks through filters and the desktop command palette; choose modern or classic task rows.
- Edit dates and other parsed details directly in Quick Add, using consistent date and time pickers across planning views.
- Review overdue tasks, reveal swipe actions on mobile, and drag a task by holding its text.
- Switch Focus tasks with a confirmation guard and clearer completion and next-task actions.
- Choose voice transcription settings, including the cloud option, and use a more compact draft panel.
- Sign in through refreshed email screens, recover a password, and see a confirmation step after registration; billing failures receive better handling.

## Backend and developer changes

- Authentication: email registration scenarios are handled consistently, masked duplicate registrations are rejected, and native OAuth callback redirects are preserved.
- Local preferences: theme customization, project icons, interface zoom, and task density are persisted.
- UI infrastructure: shared motion, scheduling controls, row dividers, and responsive settings sections replace inconsistent per-screen behavior.
- Voice and billing: draft scrolling and swipe boundaries are corrected, with broader error handling and regression coverage.
- Backend: this release focuses on client behavior and does not introduce a new backend API generation.
