# Pomodoist 1.1.3

Personal habits.

Stable tag · Source date: 2026-09-30 · Commit: [`d763b04c`](https://github.com/Kabanya/Pomodoist/commit/d763b04c90d1ed139935cc66bb38ae56371916e9)

Changes compared with `v1.1.2`.

## User experience changes

- Create personal habits with selected weekdays, daily targets, start/end dates, optional project links, and reminders.
- Record daily check-ins and follow habit completion alongside your task planning.
- Change a habit schedule while retaining its version history.
- See clearer localized payment errors and pending-payment status messages.

## Backend and developer changes

- Backend: personal habits and check-ins gain database tables, ownership rules, validation, and synchronization support through the habits migration.
- Client storage: local habit tables, repositories, schedule history, and check-in models are added, with migration and sync coverage.
- Date semantics: habit days are calendar dates rather than UTC instants; schedule versions are ordered and daily targets are validated.
- Notifications and billing: habit reminder planning is integrated, and payment status/error copy is expanded across locales.
